Support

Feather is a lightweight, read-only Markdown viewer: double-click a .md file in File Explorer and it is on screen right away. It renders Mermaid diagrams and lets you adjust readability: text width, font size, line spacing and fonts.

Requirements

  • Windows 11 (version 22H2 or later)
  • Installed from the Microsoft Store

Frequently asked questions

How do I open .md files with Feather by double-clicking?

Windows does not let apps change the default app themselves. Use either of these:

  • Start Feather without a file and press "Open Default apps settings" on the welcome screen. Choose "Feather - Markdown Viewer" as the default app for ".md".
  • In File Explorer, right-click a .md file → "Open with" → "Choose another app" → "Feather - Markdown Viewer", then press "Always".

Text looks garbled

Feather detects the text encoding (UTF-8, Shift_JIS, EUC-JP and others) automatically and shows it in the status bar at the bottom right. If text still looks wrong, please report it (see below), ideally with the file or a short file that shows the same problem.

How do I change the external editor?

Use "…" (More) at the top right → "Change external editor…". Editors that are not in the list can be chosen with "Browse…".

Images are not shown

Feather shows images on your PC (relative or absolute paths, for example next to the document) and images on the internet. Internet images depend on the site that serves them and on your connection.

A link does not open

For your safety, links to programs and scripts (.exe, .bat, .ps1 and so on) are never opened; "Open file location" shows where the file is. Other files on your PC open with their default app after you confirm.

How do I clear my settings or recent files?

"Clear all" on the welcome screen removes the recent files. Turn off "Remember recent files" in Display settings to stop recording them. Settings, recent files and logs are all removed when you uninstall the app.

Report a problem or request a feature

We use GitHub Issues (a GitHub account is required).

Report a problem or request a feature

Helpful to include in a bug report

  • The Feather version ("…" → "About")
  • The log file: feather.log in the folder opened by "…" → "Open log folder". The log contains the names of files you opened (not their folders). Remove any names you do not want to share before attaching it.
  • The Markdown file that shows the problem (only if it is fine to make it public)
