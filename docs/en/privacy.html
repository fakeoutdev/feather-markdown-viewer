Privacy policy

Effective: November 15, 2026

This policy describes the information handled by the Windows app "Feather - Markdown Viewer" (the "app").

1. Information collected

The app does not collect personal information or usage data, and does not send any to the developer or anyone else. It contains no advertising, no usage analytics and no telemetry.

2. Network connections made by the app

The app connects to the internet only in these cases:

  • Images in documents: when the Markdown document you are viewing references an image on the internet, the app loads it directly from the server that hosts it. As with any web page, that server receives your IP address and similar information.
  • Links you open: clicking a link to a web page or email address opens it in your default browser or mail app. Any further communication is made by that app.

3. Information stored on your PC

The app stores the following only on your PC and never sends it anywhere:

  • Display settings (text width, font size, fonts, theme and so on) and the location of the external editor you chose
  • The list of recently opened files (up to 10; you can turn this off in the settings)
  • An activity log (startup and errors). It may contain the names of files you opened, but not their folders (full paths).

This information is deleted when you uninstall the app. The log reaches the developer only if you attach it to a problem report yourself.

4. Microsoft Store and Windows

The app is distributed through the Microsoft Store. Information about installation, updates, purchases and app crashes is handled by Microsoft under the Microsoft Privacy Statement. The developer may receive aggregated information, such as the number of crashes, through Microsoft's developer services.

5. Changes to this policy

Any changes to this policy will be announced on this page.

6. Contact

Questions about this policy are welcome through GitHub Issues.
