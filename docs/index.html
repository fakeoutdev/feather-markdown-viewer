Feather - Markdown Viewer
プライバシーポリシーEnglish

サポート

Feather は、エクスプローラーで .md ファイルをダブルクリックするとすぐに表示される、読む専用の軽量な Markdown ビューアです。Mermaid の図の表示や、本文の幅・文字サイズ・行間・フォントなどの読みやすさの設定に対応しています。

動作環境

  • Windows 11（バージョン 22H2 以降）
  • Microsoft Store からインストールします

よくある質問

.md ファイルをダブルクリックで Feather で開くには？

Windows では、アプリが自分で既定のアプリを変更することはできません。次のどちらかで設定してください。

  • Feather をファイルを開かずに起動し、ようこそ画面の「既定のアプリの設定を開く」を押す。表示された画面で「.md」の既定のアプリに「Feather - Markdown Viewer」を選ぶ
  • エクスプローラーで .md ファイルを右クリック →「プログラムから開く」→「別のプログラムを選択」→「Feather - Markdown Viewer」を選び、「常に使う」を押す

文字化けする

Feather は文字コード（UTF-8、Shift_JIS、EUC-JP など）を自動で判定します。判定した文字コードはウィンドウ右下のステータスバーに表示されます。それでも文字化けする場合は、下の「不具合の報告」からお知らせください。可能であれば、問題のファイル（または同じ現象が起きる短いファイル）を添付してください。

外部エディタを変えたい

右上の「…」（その他）→「外部エディタを変更…」から選び直せます。一覧にないエディタは「参照…」で選べます。

画像が表示されない

文書と同じフォルダーなど、PC 内の画像（相対パス・絶対パス）と、インターネット上の画像に対応しています。インターネット上の画像は、配信元のサイトの状況やネットワークの接続状態によって表示されないことがあります。

リンクをクリックしても開かない

安全のため、実行ファイルやスクリプト（.exe、.bat、.ps1 など）へのリンクは開きません。「ファイルの場所を開く」で保存場所を表示できます。それ以外の PC 内のファイルは、確認してから既定のアプリで開きます。

設定や最近開いたファイルの記録を消したい

最近開いたファイルは、ようこそ画面の「すべて消去」で消せます。表示設定の「最近開いたファイルを記録する」をオフにすると、記録しなくなります。設定・記録・ログは、アプリをアンインストールするとすべて削除されます。

不具合の報告・ご要望

GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。

不具合の報告・ご要望を送る

不具合の報告に添付していただけると助かるもの

  • Feather のバージョン（「…」→「バージョン情報」）
  • ログファイル: 「…」→「ログフォルダーを開く」で開くフォルダーの feather.log。ログには開いたファイルのファイル名が含まれます（フォルダーの場所は含まれません）。公開したくない名前があれば、伏せてから添付してください
  • 問題が起きた Markdown ファイル（公開して問題ない場合のみ）
