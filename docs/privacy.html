プライバシーポリシー

制定日: 2026 年 11 月 15 日

このポリシーは、Windows アプリ「Feather - Markdown Viewer」（以下「本アプリ」）が扱う情報について説明します。

1. 収集する情報

本アプリは、利用者の個人情報や利用状況を収集せず、開発者を含む外部に送信しません。広告、利用状況の解析、テレメトリ（動作情報の自動送信）の仕組みは含まれていません。

2. 本アプリが行う通信

本アプリがインターネットに接続するのは、次の場合だけです。

  • 文書に含まれる外部の画像: 表示している Markdown 文書がインターネット上の画像を参照している場合、その画像を配信元のサーバーから直接読み込みます。このとき、配信元のサーバーには、一般的な Web ページの閲覧と同様に、利用者の IP アドレスなどが伝わります。
  • リンクを開いた場合: 文書内の Web ページやメールアドレスへのリンクをクリックすると、既定のブラウザやメールアプリで開きます。その後の通信は、それぞれのアプリによって行われます。

3. PC 内に保存する情報

本アプリは、次の情報を利用者の PC 内にだけ保存します。外部には送信しません。

  • 表示設定（本文の幅、文字サイズ、フォント、テーマなど）と、選んだ外部エディタの場所
  • 最近開いたファイルの一覧（最大 10 件。設定で記録しないようにすることもできます）
  • 動作ログ（起動やエラーの記録）。開いたファイルのファイル名を含むことがありますが、フォルダーの場所（フルパス）は記録しません

これらの情報は、本アプリをアンインストールすると削除されます。動作ログは、利用者が不具合の報告に自分で添付した場合にのみ、開発者に伝わります。

4. Microsoft Store と Windows

本アプリは Microsoft Store から配布されます。インストール、更新、購入、アプリの異常終了などに関する情報は、Microsoft により Microsoft のプライバシーに関する声明に従って取り扱われます。開発者は、Microsoft の開発者向けサービスを通じて、異常終了の件数などの集計情報を受け取ることがあります。

5. ポリシーの変更

このポリシーを変更する場合は、このページで告知します。

6. お問い合わせ

このポリシーに関するお問い合わせは、GitHub の Issues で受け付けています。
