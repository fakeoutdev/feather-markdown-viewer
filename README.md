# Feather - Markdown Viewer

[日本語](#日本語) | [English](#english)

## 日本語

Feather は、エクスプローラーで `.md` ファイルをダブルクリックするとすぐに表示される、Windows 11 用の読む専用の軽量な Markdown ビューアです。

- GitHub と同じ見た目の表示（GFM の表・タスクリスト・脚注など）
- Mermaid の図
- 本文の幅（制限なしも可）・文字サイズ・行間・フォント・テーマを好みに合わせて設定
- Shift_JIS・EUC-JP などの文字コードを自動判定
- データを収集・送信しません

このリポジトリは、**サポートページ・プライバシーポリシー・不具合報告（Issues）のための公開リポジトリ**です。アプリのソースコードは含まれていません。

- [サポート](https://fakeoutdev.github.io/feather-markdown-viewer/)
- [プライバシーポリシー](https://fakeoutdev.github.io/feather-markdown-viewer/privacy.html)
- [不具合の報告・ご要望](https://github.com/fakeoutdev/feather-markdown-viewer/issues/new/choose)

## English

Feather is a lightweight, read-only Markdown viewer for Windows 11: double-click a `.md` file in File Explorer and it is on screen right away.

- GitHub-style rendering (GFM tables, task lists, footnotes and more)
- Mermaid diagrams
- Adjustable readability: text width (including unlimited), font size, line spacing, fonts and theme
- Automatic text encoding detection (UTF-8, Shift_JIS, EUC-JP and others)
- Collects and sends no data

This repository hosts **the support pages, the privacy policy and issue tracking**. It does not contain the app's source code.
